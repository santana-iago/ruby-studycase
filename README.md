Esse repositório é um caso de estudo de Ruby que fiz para a disciplina de Linguagens de Programação do CEFET-MG.

Aqui reuni oito exemplos de funcionalidades do Ruby que achei interessantes ou que se destacam de outras linguagens, junto com os testes, comparações com outras linguagens e o relatório completo do trabalho.

Usei principalmente os conteúdos do Fabio Akita, do blog AkitaOnRails, na época que ele era de fato sobre Ruby, como referência para estudar alguns recursos interessantes da linguagem.
